# Помойка DROP – первый рабочий макет (v0.1)

Пародийная браузерная коллекционная игра. Предметами являются числа, мемы, персонажи, бананы, видео, абстрактные явления и скины-пародии на CS2. Все цены и предметы вымышленные, настоящие деньги не используются.

## Запуск

Открой `index.html` в браузере. Никаких `npm install`, Node.js, сервера или сборки не требуется.

Для локального HTTP-сервера (не обязательно): `python -m http.server 8000`, затем `http://localhost:8000`.

## Публикация на GitHub Pages

Файлы `index.html`, `styles.css`, `app.js`, `favicon.svg` должны лежать в корне ветки `main`.

GitHub → Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save. Сайт будет доступен по адресу, который GitHub Pages покажет в настройках.

## Что работает

- 8 тематических платных кейсов и ежедневный бесплатный кейс;
- большой каталог мемных наград с уникальными названиями, описаниями и редкостью;
- виртуальная валюта, взвешенные шансы, анимированная рулетка;
- инвентарь, продажа предметов, фильтры;
- апгрейд одного предмета в более дорогой с шансом успеха;
- пародийный режим стримера с открытым управлением шансами;
- каталог коллекций, поиск и просмотр подробностей;
- localStorage, экспорт и импорт сохранений;
- мобильная адаптация и поддержка reduced motion.

## Ограничения первого макета

- Арты предметов пока представлены типографикой и emoji. Для релиза понадобятся индивидуальные иллюстрации и редактура мемных отсылок.
- Экономика и шансы демонстрационные, без сервера, античита или публичного рейтинга.
- Ежедневная награда привязана к локальной календарной дате устройства; пользователь может менять часы/данные браузера. Для реального соревнования нужен сервер.
- Сохранение привязано к браузеру. При очистке данных сайта оно может пропасть, поэтому предусмотрен экспорт.
- Сайт не связан с Valve, Steam, блогерами, GTA или площадками кейсов.

## Файлы

- `index.html` – разметка и основные экраны;
- `styles.css` – стили, адаптация, анимации;
- `app.js` – данные предметов и кейсов, игровые механики, рендеринг, сохранения;
- `favicon.svg` – иконка.
