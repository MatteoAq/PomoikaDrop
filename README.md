# Помойка DROP

Браузерная пародийная игра о коллекционировании интернет-мемов в формате сайтов открытия кейсов. Вместо единого набора скинов здесь выпадают числа, предметы, мемы, вымышленные события и отдельные пародийные скины CS2.

## Возможности

- Тематические кейсы: «42», «Самый настоящий андерграунд», «Слоп», «Нейрослоп», «Золотые ютуберы», «GTA 6», «Легенды CS2», «Общая помойка».
- Каталог из 78 коллекционных наград с индивидуальными изображениями и редкостью.
- Открытие кейсов с анимированной лентой, апгрейды, продажа предметов и инвентарь.
- Ежедневная бесплатная награда и управляемый режим стримера.
- Локальное сохранение прогресса, экспорт и импорт JSON.
- Адаптивная версия для мобильных устройств.

Сайт работает без серверной части, аккаунтов и платёжной инфраструктуры. Используется исключительно игровая валюта без возможности пополнения за реальные деньги или вывода предметов. Проект не аффилирован с Valve, платформами скинов и авторами пародируемых материалов.

## Изображения

Основные изображения кейсов и локальный атлас наград `assets/items/items.webp` подготовлены для этого проекта. Для некоторых известных интернет-мемов интерфейс может использовать ссылки на исходные публичные изображения; если источник недоступен, автоматически отображается локальная иллюстрация.

Источники внешних мемных изображений приведены в [ASSET_SOURCES.md](ASSET_SOURCES.md). Внешние изображения не включены в репозиторий. Упоминание брендов, игр и имён используется в сатирическом контексте.

## Локальный запуск

Статический сайт: `index.html`, `styles.css`, `app.js`, `assets/`. Для локального просмотра достаточно любого HTTP-сервера, например `python -m http.server 8000`.

## Статус

Проект находится в активной разработке. Количество предметов и механики будут расширяться.
