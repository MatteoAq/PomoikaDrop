# Помойка DROP

**Помойка DROP** – независимая браузерная коллекционная игра, вдохновлённая эстетикой сайтов открытия кейсов. Вместо обычного набора игровых скинов игрок собирает предметы из разных уголков интернет-культуры: мемы, числа, персонажей, бананы, явления, игровые отсылки и пародийные скины.

## Возможности

- Тематические кейсы: «42», «Самый настоящий андерграунд», «Слоп», «Нейрослоп», «Золотые ютуберы», «GTA 6», «Легенды CS2» и «Общая помойка».
- Анимированное открытие с вероятностями, зависящими от редкости.
- Инвентарь с продажей предметов и сохранением истории игрового прогресса.
- Апгрейд предметов с видимым шансом успеха.
- Ежедневный бесплатный кейс.
- Пародийный режим стримера с открытой настройкой вероятностей.
- Каталог наград с поиском и тематическими фильтрами.
- Локальное сохранение, экспорт и импорт в формате JSON.
- Адаптивный интерфейс для компьютеров и мобильных устройств.

## Технологии

Сайт работает на HTML, CSS и JavaScript без фреймворков, сборки, внешних API и зависимостей. Изображения кейсов хранятся локально в `assets/cases`. Для разработки достаточно открыть `index.html` или запустить любой статический HTTP-сервер.

## Игровая экономика

Все цены выражены исключительно в виртуальной игровой валюте. Никаких реальных платежей, розыгрыша реальных призов, операций со Steam или вывода предметов нет. Прогресс хранится в браузере (`localStorage`); экспорт JSON позволяет создавать резервные копии. Это локальная игра, а не защищённая сервером экономика.

## Статус

Проект развивается. Текущая версия – интерактивный прототип с действующими игровыми механиками и оформлением кейсов. Иллюстрации отдельных наград будут расширяться по мере развития каталога.

## Правовая информация

Проект является некоммерческой пародией и не аффилирован с Valve, Steam, упоминаемыми платформами или создателями контента. Отсылки, имена и отдельные образы используются в контексте сатиры и фанатской культуры.
